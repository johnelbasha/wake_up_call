# Wake Up Call

You just woke up and needed some help to start your day.

This application sends you an email once a day reminding you of any important documents that will expire soon such as passports, driving licences and credit cards.

Emails are sent using the Resend service, so you'll need an account to make this work. Data is kept in a simple csv file.
